## Scripts

### Build scripts

#### build.sh

The `build.sh` script compiles the Aegis platform and all associated third-party dependencies.

#### setup_pythonpath.sh

The `setup_pythonpath.sh` script sets the required PYTHONPATH environment variable after installing the `MLIR` Python packages. This script is executed during build.sh, so it usually does not need to be called manually.

#### copy_files_to_frontend.sh

Use `./scripts/copy_files_to_frontend.sh` to copy the necessary files to the following path for packaging with frontend:

```log 
./frontend/primus/
├── bin
│   ├── mlir-translate
│   └── onnx-mlir
└── lib
    ├── libAegisRuntime.so*
    └── primus_aegis.so
```

**Note**: Once you have the relevant files under `bin` and `lib`, you don't need to set the corresponding paths in the test script.

#### build_wheel.sh

Use `./scripts/build_wheel.sh` to package the frontend into the `dist/` folder:

```log
./frontend/
├── dist
│   └── primus-0.1.0-py3-none-any.whl
```

**Note**: To execute this packaging script, you need to install python `3.10+` and do the following installation:

```sh 
sudo pip install build 
sudo apt install python3.10-venv # corresponding to the python version 
```

#### update_dialect_files.sh

The `update_dialect_files.sh` script generates documentation for the custom `SecretDialect` and `FHEDialect` in the aegis framework.

### Test scripts

#### test_binding.sh

- Test binding level

#### test_cpp_to_bin.sh

The `test_cpp_to_bin.sh` script verifies that code generated by the Aegis framework can be compiled into binary files.

Usage:

```shell
test_cpp_to_bin.sh /path/to/xxx.cpp
```

Prints Pass" if compilation succeeds, otherwise "Fail".
> Its primary purpose is to avoid running `make aegis` for full-project testing, allowing convenient testing of individual cases. 

#### test_emit_to_cpp.sh

The `test_emit_to_cpp.sh` script converts MLIR code in the EmitC dialect to C++ source files.  

Usage:  

```shell
./test_emit_to_cpp.sh /path/to/xxx.mlir
```

Prints "Pass" on successful conversion, "Fail" otherwise.
> Its primary purpose is to avoid running `make aegis` for full-project testing, allowing convenient testing of individual cases. 

#### test_mlir_to_cpp.sh

The `test_mlir_to_cpp.sh` script performs a two-stage conversion:
1. Converts MLIR from the Builtin dialect to the EmitC dialect;
2. Translates the resulting EmitC-dialect MLIR to C++ code;

Usage:

```shell
./test_mlir_to_cpp.sh /path/to/xxx.mlir
```

Prints "Pass" on successful conversion, "Fail" otherwise.
> Its primary purpose is to avoid running `make aegis` for full-project testing, allowing convenient testing of individual cases. 

#### test_mlir_to_mlir.sh

The `test_mlir_to_mlir.sh` script applies MLIR-to-MLIR transformations through a series of optimization passes.  

Usage:  
```shell
./test_mlir_to_mlir.sh /path/to/xxx.mlir
```

Prints "Pass" on successful conversion, "Fail" otherwise.
> Its primary purpose is to avoid running `make aegis` for full-project testing, allowing convenient testing of individual cases.  

#### openfhe_cpp_to_bin.sh

The `openfhe_cpp_to_bin.sh` script compiles user-written OpenFHE code into executable binaries.​

Usage:  
```shell
./openfhe_cpp_to_bin.sh /path/to/xxx.mlir
```
